# Public Assets

## Required Files

### Background Video
- **File:** `bgvideo.mp4`
- **Location:** `/public/bgvideo.mp4`
- **Purpose:** Hero section background video
- **Specifications:**
  - Format: MP4
  - Recommended resolution: 1920x1080 or higher
  - Recommended duration: 10-30 seconds
  - Should be optimized for web (compressed)
  - Should loop seamlessly
  - Content: Industrial/manufacturing/logistics footage

### Gallery Images
Create a `gallery` folder and add the following images:

- `buyer-dashboard.png` - Screenshot of buyer dashboard
- `raise-request.png` - Screenshot of request form
- `matching-screen.png` - Screenshot of supplier matching
- `order-tracking.png` - Screenshot of order tracking map
- `analytics.png` - Screenshot of analytics dashboard
- `supplier-panel.png` - Screenshot of supplier panel

**Image Specifications:**
- Format: PNG or JPG
- Recommended size: 1200x800px
- Aspect ratio: 3:2 or 16:9

## Current Status
The landing page components are configured to use these assets. Until the actual files are added:
- Hero video will show a fallback (black background)
- Gallery will show placeholder icons
